# 대전 갈마동 화재 지원 출동 웹페이지

사용자가 제공한 실제 HTML을 바탕으로 구성했습니다. 상단 2단 고정 메뉴, 사진 슬라이드, 화재 개요 표, 대응·지원 현황 카드 및 보도 링크를 포함합니다. 보고서 이미지는 페이지에 삽입하지 않습니다. 확인되지 않은 중계급수 실적·복귀 등은 단정하지 않습니다.

## GitHub → Netlify
1. 압축 해제 후 index.html, netlify.toml, assets 폴더를 저장소 최상위에 업로드합니다.
2. Netlify에서 GitHub 저장소를 연결합니다.
3. 빌드 명령: 비움 / 게시 디렉터리: .

Tailwind CSS, Font Awesome, Google Fonts는 CDN을 사용하므로 인터넷 연결이 필요합니다. 사진 4장은 assets 폴더에 포함하며 슬라이드는 2장을 표시합니다. 자동 전환은 3초 주기이며 일시정지 버튼을 제공합니다. 사진 출처는 SOURCES.md를 참고하세요.
