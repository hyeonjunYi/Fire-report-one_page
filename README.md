# 금산 에스제이이엔지 공장 화재 상황보고
첨부 관제기록과 사진을 근거로 작성한 정적 1페이지 웹 보고서입니다.

## 게시 방법
ZIP을 풀어 index.html, style.css, app.js, assets 폴더, netlify.toml을 GitHub 저장소 최상위에 함께 올립니다. Netlify에서 해당 저장소를 연결합니다. 빌드 명령은 netlify.toml 사용, 게시 디렉터리는 . 입니다. Hugo가 필요하지 않습니다. 로컬에서는 index.html을 열어 볼 수 있습니다. 추가 API 키·서버·라이브러리가 필요하지 않습니다.

## 내용 기준
- 긴급구조별 관제진행상황 13쪽(2026.11.03. 07:48 출력)과 현장사진 3장.
- 06:20:22 접수, 06:29:34 두마화학 추가 출동지령, 06:38:00 출동보고, 07:13:38 현장도착, 초진 06:46 및 완진 07:24.
- 인명피해 없음은 06:45:10 보고 시점 기준. 최종 인명·재산피해 확정 자료는 아님.
- 대원: 사용자 제공 소방위 임한영 1명. 개별 임무·방수·잔화정리 실적은 확인되지 않아 기재하지 않음.
- 주소는 최종 관제 표제 기준 신평리 842-4. 초기 신고 주소는 여러 차례 수정돼 생략.
- 사진은 5초 간격으로 3장 순환. 이전/다음/정지 버튼 지원. 인쇄 시 첫 사진과 1장 요약 레이아웃 적용.
- 원본 관제 PDF의 전화번호 등은 웹 보고서에 포함하지 않았습니다.
