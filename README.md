# 천안 이랜드패션 물류센터 화재 계룡소방서 지원 출동 현황

충남 천안시 동남구 풍세면 이랜드패션 물류센터 화재 사고(대응 2단계)에 따른 충남 계룡소방서 지원 출동 현황 웹페이지 패키지입니다.

## 파일 구성
- `index.html`: 메인 웹페이지 (반응형, 인쇄 최적화)
- `style.css`: 정돈된 CSS 스타일시트
- `netlify.toml`: Netlify 배포 설정 파일
- `SOURCES.md`: 자료 출처 및 사실 기술 원칙
- `assets/`: 보고용 정적 에셋 폴더

## Netlify 배포 방법
1. 본 압축 파일(`cheonan_eland_fire_report.zip`)을 Netlify 대시보드의 **"Sites > Deploy manually"**에 드래그 앤 드롭합니다.
2. 또는 압축 해제 후 GitHub 저장소에 푸시하여 연동 배포합니다.
