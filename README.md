# 천안 이랜드패션 물류센터 화재 지원 출동 보고

설치·빌드 없이 작동하는 정적 웹페이지입니다. 외부 CSS·폰트·스크립트 의존성 없이 사진도 로컬 파일로 포함했습니다.

## GitHub → Netlify 게시
1. ZIP을 압축 해제합니다.
2. index.html, style.css, app.js, netlify.toml과 assets 폴더를 GitHub 저장소 최상위에 업로드합니다. ZIP 자체를 올리지 않습니다.
3. Netlify에서 Git 저장소 가져오기로 해당 저장소를 연결합니다.
4. 빌드 명령은 비우고 게시 디렉터리를 `.`으로 설정합니다.
5. 배포를 실행합니다. index.html이 들어 있는 폴더를 Netlify 수동 배포에 올려도 됩니다.

## 내용 수정
- 본문·지원 대원: index.html
- 디자인·반응형·인쇄: style.css
- 사진 전환·사진 설명·공유: app.js
- 사진: assets/

명단은 관서 제공사항으로 엄사고가차(소방위 박동선), 엄사물탱크(소방위 심영문), 두마화학(소방장 박완규)을 기재했습니다. 제공된 인원은 3명이며 차량별 전체 탑승 인원으로 추정하지 않았습니다. 구체적인 현장 임무, 출동·도착·복귀 시각은 미제공으로 기재하지 않았습니다.

나무위키 링크는 접근 제한으로 읽지 못해 페이지 출처 카드에서 제외하고, 확인된 언론 보도를 사용했습니다. 이전 갈마동 화재 자료나 사진은 이 묶음에 포함하지 않았습니다.

사진은 제3자 저작물이며 출처 표기가 재사용 허락을 의미하지 않습니다. 외부 공개 전 이용 범위를 확인하세요. 상세 출처와 정보 기준은 SOURCES.md에 기록했습니다.
