# 현장 화재보고서

- `index.html`: 현재 상황보고서 페이지
- `editor.html`: 휴대폰 작성 페이지. 입력 내용은 브라우저에 임시 저장되며, 미리보기와 게시용 `index.html` 다운로드를 지원합니다.
- 편집기는 작성자 전화번호를 입력하면 보고서에 연락처를 표시합니다. 번호를 제공하지 않으셔서 현재 보고서에는 번호를 임의로 넣지 않았습니다.
- 사진은 브라우저에서 긴 변 1,600px 이하로 축소한 뒤 게시용 HTML에 포함됩니다.
- 편집기에서 `게시용 HTML 다운로드`를 누르고, 내려받은 파일을 GitHub Pages 저장소의 `index.html`로 올려 게시합니다. 공개 저장소에 GitHub 토큰을 입력하거나 소스에 저장하지 않습니다.
- `SOURCES.md`의 제3자 사진 이용 안내를 확인하고, 새 보고서에는 사용 권한이 있는 사진만 올리십시오.
