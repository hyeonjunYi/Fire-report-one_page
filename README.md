# 현장 화재보고서

- `index.html`: 현재 상황보고서 페이지
- `editor.html`: 휴대폰 작성 페이지. 입력 내용은 브라우저에 임시 저장되며, 미리보기·게시용 HTML 다운로드·GitHub 직접 게시를 지원합니다.
- 편집기는 작성자 전화번호를 입력하면 보고서에 연락처를 표시합니다. 번호를 제공하지 않으셔서 현재 보고서에는 번호를 임의로 넣지 않았습니다.
- 사진은 브라우저에서 긴 변 1,600px 이하로 축소한 뒤 게시용 HTML에 포함됩니다.
- GitHub 직접 게시를 쓰려면 소유자·저장소·브랜치와 Contents 읽기/쓰기 권한을 가진 세분화 토큰을 입력합니다. 토큰은 브라우저 탭 세션에만 보관되며 소스·보고서·커밋에 포함되지 않습니다. 게시를 누르면 저장소 루트 `index.html`을 새 커밋으로 교체합니다. HTML 다운로드도 예비 수단으로 남겨 두었습니다.
- `SOURCES.md`의 제3자 사진 이용 안내를 확인하고, 새 보고서에는 사용 권한이 있는 사진만 올리십시오.
